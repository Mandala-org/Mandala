Numerical and inference conventions
  Silicon training used scale_1 only: 80 training and 16 validation structures,
  split seed 43, sigma 0.02 Angstrom, original generation seed 7. The larger
  silicon cells use this training sigma, a=5.4437 Angstrom, independent Gaussian
  displacements and the individually recorded seeds in structures/manifest.json.
  The SiO2 perturbation sigma is 0.02 Angstrom. Tiled controls are unperturbed.
  Source validation members are taken from the committed physical-constraints
  audit; retain its caveat that historical membership was reconstructed.

  Fixed paper checkpoint paths and envelope artifact are in workflow.py and
  results/*_provenance.json. Use explicit legacy_2026_07 FiLM semantics. A base
  CIF goes through the identical structure-only path and is compared against
  frozen historical inference before any larger-cell inference is accepted.
  OpenMX -> e3nn conversion MUST include the Cartesian convention used by
  Snapshot._change_basis: positions and row lattice vectors right-multiplied
  by eye(3)[[2,0,1]]. CIF files and DFT inputs remain in the OpenMX frame.
  Reference density is multiplied by two: the historical density heads predict
  the restricted-total kernel, whereas the OpenMX parser returns one spin.
  Native prediction H is in Hartree; H MAE is converted to meV only in reports.

  Initial inference omitted that Cartesian conversion. Its 142--147 meV tiled
  errors are INVALID. Those operators and JSON are preserved only under
  .../physical_constraints/r6_supercell_20261110/invalid_unpermuted_cif/.

Physical diagnostics and support
  Raw directed predictions are saved without Hermitian projection, overlap
  jitter/clipping, density rescaling, or retraining. Raw Hermiticity is measured
  first; spectral diagnostics explicitly use Hermitian parts, as in the audit.
  Occupations are reported only where the predicted overlap is usable.
  Tr(DS) is also evaluated directly in real space, even for invalid metrics.
  Silicon diagnostics use uniform Gamma-centered 4x4x4 (64 atoms) or 3x3x3
  (216 atoms) meshes via analysis.physical_constraints.uniform_kpoints. These
  follow the audit's sampling convention and do not certify the entire BZ.
  OpenMX's SCF sampling remains whatever the preserved input specifies.
  SiO2 predictions contain H only: report Hermiticity without borrowing S.

  Main prediction diagnostics use the full geometry graph. A separately named
  reference-support control permits comparison with the paper audit. Both raw
  and Hermitian-projected common-support element MAEs, unmatched blocks and
  scalar counts are in JSON; the Markdown table uses Hermitian projection to
  match paper validation H MAE: Si 0.435164 meV; SiO2 1.99588 meV.
  Probe baseline files compare the same source-cell support choices. A parent
  head-routing replay, when present, is a labelled diagnostic on a perfect
  tiling only and never changes primary predictions or learned parameters.

  Positive-definite success per k point is also affected by exact band folding:
  a supercell Bloch matrix contains several primitive-cell Bloch spectra and
  is positive definite only when all contributing primitive spectra are.
  Therefore a lower per-k success fraction alone does not prove degradation.
  Also compare minimum eigenvalues and charge traces against the folded source
  prediction. In the 2x silicon tiled control, the source full-support minimum
  (-0.373983) becomes -0.990323 in the model's supercell prediction; on reference
  support the source minimum is -0.00125371 versus -0.381301. Pure folding on
  the matched 8-to-4 diagnostic meshes would preserve those global minima.

Folded controls and k sampling
  Folding preserves the infinite real-space operator by changing atom/image
  labels. For source tile t and primitive translation R, destination tile is
  (t+R) mod repetitions and supercell translation is floor((t+R)/repetitions).
  ASE tile-major atom order is preserved and tested analytically.
  The 2x silicon SCF mesh 4x4x4 preserves the original 8x8x8 k density.
  8/3 is not integral: the 3x silicon SCF mesh 3x3x3 is slightly denser (9x9x9
  primitive density). The 3x tiled control folds the original 8-mesh operators;
  it is an exact algebraic representation control, not a new 9-mesh SCF result.
  Original Gamma sampling of the 150-atom SiO2 cell corresponds to Gamma and
  an X-type point for the 2x1x1 supercell. Its folded control is an exact DFT
  reference only if original Gamma sampling was converged. No k-convergence
  study is asserted by this experiment.
