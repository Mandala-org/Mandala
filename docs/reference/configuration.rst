Configuration reference
=======================

Every field of :class:`net.common.Config` with its type and default,
generated from the source. Fields can appear at the root of a YAML document,
be set with ``--set field=value`` or be passed to ``Config(...)``. Sectioned
keys (``data``, ``training``, ``pipeline``…) are described in
:doc:`../user_guide/configuration` and :doc:`../architecture/pipeline`.
