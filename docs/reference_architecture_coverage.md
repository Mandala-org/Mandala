# Reference architecture coverage

The reference presets are checked against pinned source model computations.
Architecture mathematics and training-controller fidelity are separate acceptance
boundaries; short Adam traces alone do not certify the complete training
procedure. Recipes use reusable transformations inside one MANDALA `E3GNN`
and do not import upstream model classes in production.

| Preset | Audited upstream commit | Implemented default structure |
|---|---|---|
| `configs/reference/deeph.yaml` | DeepH-pack `141faaaba1d5e17248283ef939bcd2ead2d8e677` | Five gated crystal message layers, cross-block residuals, endpoint-local environments, native local orbital readout |
| `configs/reference/deeph_e3.yaml` | DeepH-E3 `036bf95b996052ef778c5c38e3c54c2ac0e2b591` | Three ordered node/edge stages, factorized tensor products, separate Gaussian encodings, canonical harmonics, graph field normalization, shared shell readout |
| `configs/reference/mace_h.yaml` | MACE-H `3d6248b715eef302a4fd674d52bcd69254596a51` | Three neighbor-density/correlation stages, retained feature stream, three degree expansions and edge stages, intentional identity-backward affine scaling |

Pins identify inspected executable implementations. Paper names alone do not
specify historical dependency versions or every optional upstream branch.
The source matrix includes real spinless and supported complex SOC codecs.
Preset default widths are retained; differential optimizer tests reduce widths
and angular degree while keeping the complete default layer topology.

## Acceptance evidence

| Boundary | Focused evidence |
|---|---|
| Native import and support | Independent original DeepH frame/rotated-target/graph preprocessing; DeepH-E3 and MACE-H graphs/labels, including SOC; periodic keys, missing entries, unequal species blocks |
| Primitive computations | Source initialization, parameter layouts, forward values, input/parameter VJPs; factorized tensor products, normalization, radial encodings, contractions, degree expansions, gated/local messages |
| Complete models | Five-layer local network and three-layer coupled networks against pinned executables; decoded outputs, gradients and three fresh Adam updates; coupled networks include SOC |
| Offline independent evidence | Five source-generated JSON fixtures with commit, source hashes, runtime, inputs, initialization/gradient/update probes and three-step traces |
| Training integration | All three presets through native data, CLI, real forward/backward and Lightning fit; spinless and complex SOC inputs; train-only statistics with held-out outliers |
| Continuation | Miniature MACE-H segmented and uninterrupted training produce identical full model state, including fitted statistics; existing legacy epoch-boundary tests remain applicable |
| Composability | Four standalone hybrid YAMLs, forward/backward, optimizer steps, checkpoint round trips, proper-rotation covariance, local-frame invariance, rejection of mismatched frames/bases/supports |
| Export | Native directed blocks, global/local frame inverse transforms, complex spin-major matrices, coverage masks, dtype/device preparation, label-free radius support |

Offline fixtures are generated by the upstream implementations, not by MANDALA
forward code. They probe every parameter using selected coordinates and moments;
live source comparisons additionally compare all parameter coordinates. Their
scope is model mathematics on supplied features. The separate data tests cover
preprocessing; no fixture alone establishes the entire workflow.

Oracle generation and replay use CPU PyTorch 2.5.1 and e3nn 0.5.9 in the shared
test environment. Float64 is used for strict comparisons, with original DeepH
initialized in its native float32 Gaussian path before conversion. Historical
e3nn/PyTorch stacks and cross-GPU bitwise equality are not certified.

The initial reference-architecture implementation check passed 214 tests; two
CUDA-only checks were skipped because this environment has no CUDA device. This selected the
new transformation, codec, data, recipe, fixture, inference and training tests,
plus the existing E3GNN configuration and epoch-boundary regression files.
Ruff and Git whitespace checks also passed. Unrelated test directories were
not executed.

## Interface-unification verification

The combined focused verification of the shared interfaces passed **227 tests**;
26 checks were skipped because the optional upstream source checkouts or CUDA
were unavailable. It includes real CLI training, complex SOC input, exact
segmented continuation, upstream-generated numerical fixtures, hybrid graphs,
original data/cache workflows, native export and serialization, and scientific
objective composition. Nine combinations additionally exercise all three
reference graphs with original matrix, coupled-irrep and irrep-part supervision.

A representative original flat configuration (two message layers, s/p orbitals)
was compared against the pre-refactor implementation at commit
`0afa52bc8207a8d643ec772a0434ac85756f19e7`. Seeded outputs and all learned
parameter gradients matched exactly. This checks preservation of the original
construction order and default computation; it does not establish cross-device
bitwise equality or certify every possible configuration.

Force predictions match finite differences of physical energy for all three
reference graphs; force/stress parameter gradients remain finite. Batched
forward/loss/gradient comparisons verify full-batch normalization and masked
reductions. Layout/frame/unit metadata and coverage survive prediction saving
and loading. All changed Python files passed Ruff and formatting checks; Git
whitespace and SiOx launcher syntax checks passed. A final focused follow-up
passed five checks covering explicit CPU selection on GPU-capable hosts,
reference CLI training and exact continuation.

## Intentional differences and unsupported branches

Statistics are fitted on training data only. Missing entries are masked;
constant or empty statistics retain unit scale. The upstream full-dataset
statistics population is never reproduced. MANDALA's reliable restart policy is
used instead of source rollback/restart quirks. Native deterministic epoch
sampling and immutable run manifests support segmented training; identical
global RNG consumption across different upstream trainer implementations is
not claimed.

Default architecture recipes are covered. Optional original DeepH GAT/PAINN
variants, nondefault spherical-Bessel angular features, raw DFT executable
preprocessing and every historical package flag are not claimed as certified
reference presets. Existing MANDALA attention and radial alternatives remain
available as explicitly configured components. Unsupported transform names or
options fail rather than selecting an approximation. Upstream assert-disabled
or unfinished flags are not exposed as apparently functional options.

The unified training step composes masked operator MSE/MAE, irrep objectives,
envelope transforms, observable guidance, spectral loss, force and stress
supervision. Physical block reconstruction explicitly converts layout, frame,
basis and units. Reference recipes use the same DatasetFactory, Config,
E3GNN, trainer, continuation and export interfaces as original flat settings.
The separate dataset, trainer and prediction interfaces have been removed.
Fitted transforms accept packed targets and original block supervision; original
registered readouts can also use packed shell supervision.

No long publication-scale trainings or new scaling ablations are part of these
software checks. Accuracy reproduction and benchmarking require frozen datasets,
training manifests, runtimes and separately executed experiments.

## Regenerate independent fixtures

Check out the pinned unmodified source trees, then run:

```bash
PYTHONPATH=src:. python -m scripts.generate_reference_fixtures \
  --deeph-root /path/to/DeepH-pack \
  --deeph-e3-root /path/to/DeepH-E3 \
  --mace-h-root /path/to/MACE-H --model all

PYTHONPATH=src:. python -m scripts.generate_reference_fixtures \
  --deeph-e3-root /path/to/DeepH-E3 \
  --mace-h-root /path/to/MACE-H --model all --spinful
```

The generator validates commit/source identity. Older DeepH PyG typing omits
the `distance` argument from a generated propagation signature; the oracle uses
the unchanged generic PyG dispatcher. Direct source model constructors avoid
stale `spinful=False` keywords in the coupled upstream kernels. These isolated
adapters change no network equations and are not production dependencies.

MIT notices for adapted DeepH-E3/MACE-H and their dependencies are retained in
the transformation/codec files and `src/net/transforms/coupling/MIT.md`.
Original local-message formulas are implemented as reusable operations; no
independent DeepH model implementation is vendored into MANDALA.


## Critical-review follow-up

The shared graph uses canonical xyz global features, with normalization at input
representation construction and coordinate decoding at native reconstruction.
Upstream-generated fixtures remain unchanged and retain their original strict
output, gradient and three-step Adam tolerances. Frame changes remain explicit
mathematical operations; they are distinct from Cartesian convention changes.

Additional acceptance cases cover original-component basis rejection and support
preservation, canonicalization of external features, unequal-size batching of
custom and mixed entity relations, negative mapping sentinels, independent
periodic message graphs, and fixed topology during geometric differentiation.
A scalar message/envelope/reducer composition is compared with the reference
composite. A new configuration combines tensor-product messages and projected
attention and receives the same gradient, serialization and covariance checks
as the existing hybrid configurations.

The public DeepH CLI is additionally compared with a manual source-style
norm-clipped Adam loop, including optimizer state and actual scheduler ordering.
Early milestone events make this an inexpensive real training test; a separate
controller test crosses the original 500/2000/3000 epoch boundaries and verifies
continuation state. These are focused numerical checks, not long scientific
accuracy experiments or cross-GPU reproducibility certification.


Verification on 2026-10-22: **232 passed, 41 skipped** in the focused selection
covering the changed interfaces, compositions, reference fixtures, original
layers/configurations, force/stress paths, data caches, native inference,
training launchers and public training workflows. Skips require optional pinned
upstream source checkouts; the five committed upstream numerical fixtures were
executed without changing their data or tolerances. Ruff, Black formatting and
Git whitespace checks passed. GPU execution and publication-scale accuracy
experiments were not part of this verification.
